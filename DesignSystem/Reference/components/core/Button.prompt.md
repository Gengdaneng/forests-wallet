The standard action button; use `size="child"` on any surface Forrest touches, `size="parent"` on Dad's iPhone.

```jsx
<Button tone="accent" size="parent" icon="plus" onClick={add}>加进来</Button>
```

Tones: `primary` (spruce, confirmations), `accent` (honey, the money-entry action), `quiet`/`outline` (secondary), `danger` (device revoke only — never for spending). Presses scale down, they don't change hue.
