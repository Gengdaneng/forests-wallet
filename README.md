# Forest 的钱包

家庭虚拟零花钱记录与金融教育 App。  
只记录数字，不承载、不转移、不托管真实资金。

本文档是当前产品需求说明（PRD）。体验基准来自已评审的 iPhone / iPad 原型，不再继续改原型方向。

## 产品是什么

Forest 在 iPad 上查看自己现在有多少可用零花钱、为什么变了、规则是什么、储蓄目标进展到哪。  
家长在 iPhone 上记录增加、消费、修正和规则。确认页始终说明：**没有真实资金移动**。

这不是儿童银行，不是支付工具，也不是普通余额追踪器。它是一本给 Forest 看懂的家庭手账。

## 谁在用

- **Forest**：主要在 iPad 上，只读。
- **家长**：主要在 iPhone 上，负责全部写入。

当前工作目标是 Forest 单人家庭试点。界面可以预留多儿童形状，但 MVP 不承诺共同家长或多名儿童。

## 已确定的产品事实

| 项 | 决定 |
|---|---|
| 货币 | 人民币 CNY，按中国地区习惯显示，例如 `RMB ¥38.5` |
| 儿童余额语言 | “你现在有” + “可用零花钱” |
| 真实性说明 | “家庭记录 · 不是真钱”，独立呈现，不污染每个核心概念 |
| 借款预览语言 | “提前拿到 / 以后还” |
| 视觉方向 | 自然观察手账，不是儿童银行 |
| 标志 | 可爱存钱罐 |
| 规则 | 可同时有多条；分为固定规则与临时规则 |
| 设备操作 | 称“撤销”，不称删除设备 |
| 家长导航 | 底部导航固定，不随内容滚动 |
| 账目 | 已确认记录不可删除；错误用冲正 + 正确替代记录修正 |
| 联网 | 儿童离线可读最后确认缓存；V1 家长写入必须联网并等待服务端确认 |
| 储蓄 | 属于 MVP |
| 借款、偿还、利息、信用 | 仅后续概念预览，不进入 MVP |

未在上表写死的界面细节（气质微调、阅读阶段、首页第一重点、儿童导航骨架、Face ID 频率、庆祝强度、类别词汇、储蓄措辞、教育深度、上架范围等）仍是开放项，实现时不得把推荐默认值悄悄当成已批准需求。

## 产品原则

1. Forest 看到的是“我现在有多少、为什么变了”，不是账户、转账或练习金额。
2. 家长记录的是虚拟家庭账本。确认语言说“已记录”，绝不说“已转账”。
3. 儿童与家长是两套信息密度和导航，不是同一套界面换皮肤。
4. Face ID 只是敏感操作的本地体验门；最终权限由服务端强制执行。
5. 历史不可抹掉。儿童看到“我们把金额改对了”；家长看到原记录、冲正和正确记录的关联链。
6. 余额必须从不可变流水导出，不能靠覆盖金额。
7. 可用零花钱与为目标留出的金额分开显示，绝不重复计算。
8. 教育适时出现，不强迫上课；债务与利息必须明确隔离。

## Forest · iPad（MVP）

全部只读。

- **配对欢迎**：用孩子能懂的话说明能看现在有多少、每笔为什么变、规则和储蓄；家长负责记录；App 不会动银行卡或现金。
- **首页**：可用零花钱、最近变化、下次零花钱、储蓄进度、一则余额知识卡。
- **动态与详情**：增加、消费、修正；“之前 − 消费 = 之后”；修正审计链。
- **规则**：多条固定规则与临时规则。固定规则周期重复，条件未完成则本周不增加。临时规则是全家商量的一次事项，完成后可增加一次。临时规则用“总数 + 最近几条 + 查看全部”，避免撑坏界面。语言只说明条件、状态、结果和家长确认，不责备。
- **储蓄目标（望远镜）**：无压力进度与留出记录；目标由家长管理。
- **信任状态**：在线、离线缓存、更新失败、空账本。离线时明确“正在显示已保存信息”。

借款 / 利息只作为单独标记“不属于 MVP”的预览，没有生效中的借款。

## 家长 · iPhone（MVP）

- **敏感操作验证门**：Face ID / 设备验证演示门，并写明服务端仍做最终授权。
- **首页**：Forest、可用金额、增加 / 消费 / 修正入口。
- **增加与消费**：金额、用途、类别、日期 → 复核 → 确认 → 服务端成功。成功页写清没有真实资金移动。
- **修正**：保留原记录，写入冲正，再写入正确替代记录。
- **历史与详情**：已确认记录不可破坏性编辑或删除。
- **规则复核**：固定 / 临时规则、下次日期、金额。
- **设置**：已配对设备、撤销设备、配对新设备、导出、隐私。

家长离线时不能写入；必须提示没有写入任何记录。

## 五个必须成立的故事

1. **零花钱到账**：家长记录 +¥7 → 服务端确认 → Forest 看到新余额和原因。
2. **一次消费讲得明白**：家长记录购买 → Forest 打开详情 → 用途、日期和“之前 − 消费 = 之后”。
3. **错误被修正，而不是被藏起来**：误记 ¥14 → 冲正 + 正确记录 → 结果 ¥11，双端都看得到关联。
4. **目标看起来够得着**：Forest 打开望远镜，看到例如 ¥18 / ¥30，大约还需两次零花钱。没有倒计时、连续打卡或消费诱导。
5. **学习出现在恰当时机**：Forest 问“余额是什么？”→ 一个算例 → 可选小练习。债务与利息不伪装成已上线功能。

## 视觉与语言

方向是**自然观察手账**：沉静植物色、结实圆体字、线描与纸片插画、直接动词。  
不使用吉祥物、仿真信用卡、霓虹游戏化或金融机构式界面。

- 云杉墨绿 `#173D35`
- 新叶绿 `#D8EDD5`
- 零花钱暖黄 `#F3C968`
- 手账纸白 `#FBF7ED`

标题用 SF Pro Rounded / `ui-rounded`，正文用 SF Pro Text / 苹方。  
儿童大字只说：“你现在有”“加进来了”“花在”“已改正”“为目标留出”。  
儿童卡片圆角约 24pt，家长卡片约 16–20pt。图标始终有文字。  
确认用一次安静反馈；消费、债务、修正不做庆祝。开启“减弱动态效果”时改为静态反馈。

## 无障碍底线

- 最小触控目标 44×44pt，目标做到 48–54pt。
- 兼容动态字体；文字卡片不用固定高度。
- 增加、减少、修正不只靠红绿色。
- 进度同时写 `¥18 / ¥30`，不只靠进度条。
- VoiceOver 先说金额和含义，再提供操作。
- iPad 常规横屏可用侧栏；半屏 / 紧凑宽度改为底部导航 + 单栏，不整体缩小。

## 明确不做

- 真实资金：卡、银行、转账、托管、投资、真实信用评分
- MVP 借款、偿还、利息入账、模拟账单 / 信用
- MVP 儿童购买请求或家务打卡
- 家长离线写入、冲突合并、发件箱
- 共同家长、多名儿童作为上线条件
- 把原型里好看的界面一次性全部做完

## 建议实现顺序

1. 家长登录 / 配对，Forest 只读欢迎
2. 家长增加零花钱 → 服务端确认 → Forest 首页更新
3. 家长记录消费 → Forest 查看用途与余额算式
4. 家长修正错误 → 双端保留审计链
5. 固定 / 临时规则只读展示
6. 储蓄目标
7. 离线、空、错误和撤销设备状态
8. 最后再加最小余额知识卡
